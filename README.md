# Campus Lost & Found App

## Introduction
This is a simple Flutter application that helps students view lost and found items on campus.

## Features
- Displays 8 campus items.
- Shows item name, location, and status.
- Includes a Details button for each item.
- Opens a separate screen to view item details.
- Provides a Back button to return to the home screen.

## Technologies Used
- Flutter
- Dart
- Android Studio

## How to Run
1. Install Flutter and Android Studio.
2. Open the project in Android Studio.
3. Open `lib/main.dart`.
4. Run the application on an emulator or Android phone.

## Learning Objectives
- Learn how to use `ListView.builder`.
- Display lists of items.
- Create screens using Flutter widgets.
- Navigate between screens using `Navigator.push()` and `Navigator.pop()`.
